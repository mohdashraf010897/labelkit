# Label Kit (pre-build)

Open-source kit to mark AI-generated images, text and audio for **EU AI Act Article 50**: C2PA + IPTC provenance, a disclosure label, an audit log and a CI `verify` check.

**Status:** demand check. Nothing is built yet. 👍 the [waitlist issue](https://github.com/mohdashraf010897/labelkit/issues/1) if you'd use it.
